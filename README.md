# Alami Villa — Bali Honeymoon Redesign

This branch contains the Bali-inspired honeymoon villa direction for Alami Villa.

## Existing site preserved

The repository remains a static multi-page site with:

- Home
- The Villa
- Location
- Experiences
- Gallery
- FAQs
- Book Your Stay

## New admin UI

Open `dist/admin.html` for the responsive owner dashboard concept. It includes:

- Booking overview and revenue cards
- Booking source and approval states
- AI inbox with human handoff indicators
- Guest-message automation timeline
- Quick actions for content, prices and manual bookings
- Mobile responsive navigation

## API integration points

The UI currently uses safe mock states until the owner supplies credentials and selected providers. The following should be connected next:

- Channel manager availability and rates
- Booking request approval and payment link
- WhatsApp, Instagram and Messenger inbox
- AI concierge provider
- Email and WhatsApp guest automations
- Google Analytics, Meta Pixel and Search Console

No API keys are committed in this repository. All provider accounts should remain owned by the villa customer.

## Design direction

Warm Bali honeymoon retreat: deep forest, charcoal, ivory, muted champagne, editorial serif typography, cinematic imagery, subtle motion, clear direct-booking CTA and mobile-first touch targets.
